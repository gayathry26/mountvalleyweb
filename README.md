# Mount Valley Public School — Official Website

A premium, modern, and professional static web portal for **Mount Valley Public School**, featuring responsive layouts, authentic school photography, and an interactive Framer Motion animation system.

## 🌟 Tech Stack

- **Framework**: React.js 18
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Routing**: React Router DOM (v6)
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/gayathry26/mountvalleyweb.git

# Navigate into the project folder
cd mountvalleyweb

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Compile and bundle for production
npm run build

# Preview production build locally
npm run preview
```

## 📁 Pages Included

1. **Home (`/`)**: 9 comprehensive sections including full-screen building hero, academic overview, laboratory showcases, why choose us, and admission CTA.
2. **About Us (`/about`)**: School background, Vision & Mission, 4-pillar educational philosophy, and campus building environment.
3. **Academics (`/academics`)**: Curricular methodology, classroom environment, practical laboratory science, and student development framework.
4. **Campus Life (`/campus-life`)**: Dedicated infrastructure showcase of physics and chemistry laboratories, student activities, and campus life.
5. **Gallery (`/gallery`)**: All 7 authentic school photographs with category filtering and an interactive keyboard-navigable Lightbox modal.
6. **Admissions (`/admissions`)**: 4-step admission guide, document checklist, and interactive enquiry form with client-side validation.
7. **Contact Us (`/contact`)**: Campus office details, interactive Google Maps embed with turn-by-turn directions link, and direct contact form.
